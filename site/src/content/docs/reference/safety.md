---
title: Safety
description: The laser, the fumes and fire.
---

:::danger[Eyes]
The fiber laser beam is invisible and can blind you instantly. Wear OD6+ goggles rated for 1064 nm every time the laser is on.
:::

:::danger[Fumes]
Burning FR4 and UV solder mask makes toxic fumes and dust that can cause cancer. Run the fume extractor, or vent outside.
:::

:::caution[Fire]
The laser can set the black paper or debris alight. Never leave it running unattended.
:::
