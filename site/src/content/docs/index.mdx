This guide makes **two-sided PCBs** with a **fiber laser** and a **CNC router**.

<Aside type="caution" title="No plated holes">
Holes are not plated, so nothing connects the top copper to the bottom copper. Rivets, a wire soldered through the hole, or soldering the part on the top side might work, but none of them has been tested yet.
</Aside>

## Process summary

The board visits five stations in this order: **CNC → laser → bench → laser → CNC**. The hard part is putting it back in exactly the same place each time. See [Alignment](/machining/alignment/).

## Prerequisites

- A board designed in KiCad with [KP's design rules](/designing/design-rules/).
- The [software installed](/reference/install-software/) and [set up](/reference/software-setup/).
- The [tools and materials](/reference/requirements/).
- A calibrated laser: [pen settings](/reference/pen-settings/) saved from the [calibration test](/reference/laser-calibration/).
- You can run the fiber laser in BslAppSimple and the CNC in Mach3.

<Aside type="danger" title="Laser on, goggles on">
The beam is invisible. Read [Safety](/reference/safety/) before you use the laser.
</Aside>
